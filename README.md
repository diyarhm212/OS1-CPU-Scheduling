OS1 - CPU Scheduling Simulator

Project Description

A CPU Scheduling Simulator implemented using Python for Operating Systems 1.

The project compares two CPU scheduling algorithms:

- FCFS (First Come First Served)
- Priority Scheduling (Non-Preemptive)

Features

- Reads process information from "input.txt".
- Calculates Waiting Time.
- Calculates Turnaround Time.
- Calculates Response Time.
- Displays a Gantt Chart.
- Handles CPU Idle Time.
- Compares the average Waiting Time of both algorithms.

Input Format

Each process is entered using four values:

"Process_Name Arrival_Time Burst_Time Priority"

Example:

P1 0 4 2
P2 0 3 2
P3 0 2 1

How to Run

Make sure Python is installed, then run:

python main.py

Project Files

- "main.py" - Main Python program.
- "input.txt" - Input processes.
- "README.md" - Project documentation.
